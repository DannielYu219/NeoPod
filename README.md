# NeoPod

NeoPod是一个iOS应用，提供音乐、视频和应用商店功能。

## 功能特性

- 音乐播放功能
- 视频播放功能
- 应用商店
- SMB客户端
- Navidrome API集成
- 开发者模式

## 项目结构

```
NeoPod/
├── NeoPod/              # 主应用目录
│   ├── Assets.xcassets/  # 应用资源
│   ├── NeoPod.xcdatamodeld/  # 数据模型
│   ├── *.swift           # Swift源代码文件
│   └── test_plugin.html  # 测试插件
├── NeoPod.xcodeproj/     # Xcode项目文件
├── app_market/           # 应用市场相关文件
└── 第三方应用开发者指南.md  # 第三方应用开发者指南
```

## 安装与运行

1. 克隆仓库：
   ```bash
   git clone https://github.com/DannielYu219/NeoPod.git
   ```

2. 打开 `NeoPod.xcodeproj` 文件

3. 选择目标设备并运行应用

## 开发环境

- Xcode
- Swift
- iOS SDK
